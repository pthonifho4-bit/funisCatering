# Funis Catering & Events Website

## Files
- `index.html` — homepage and all site sections
- `css/styles.css` — responsive styling and blue/white visual identity
- `js/main.js` — mobile navigation, gallery lightbox, and current footer year
- `assets/` — supplied Funis logo and supplied project photographs

## Preview locally
Open `index.html` in a modern browser. Keep the `css`, `js`, and `assets` folders beside it.

## Publish
Upload the contents of this folder (not the ZIP file itself) to your hosting provider's public web root, commonly `public_html` or the hosting dashboard's deploy folder.
